# Secure File Sharing System

A full-stack secure file sharing web application built using React, Node.js, Express.js, and MongoDB.
.
## Features

* JWT Authentication
* AES-256 File Encryption
* Secure File Upload & Download
* Protected Routes
* Access Control
* MongoDB Database Integration

## Technologies Used

### Frontend

* React.js
* Axios
* React Router

### Backend

* Node.js
* Express.js
* MongoDB
* JWT
* Multer
* Crypto

## Security Features

* AES Encryption for files
* JWT Authentication
* Access Control
* Input Validation
* XSS Protection

## Installation

### Backend Setup

```bash
cd backend
npm install
nodemon server.js
```

### Frontend Setup

```bash
cd frontend
npm install
npm start
```
